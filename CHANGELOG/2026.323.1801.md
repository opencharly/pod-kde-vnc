# 2026.323.1801 — feat(kde-vnc): fullscreen GPU-accelerated KDE Plasma nested in headless sway, served over wayvnc, on pod-cdi

## Summary

The first landing of **pod-kde-vnc**: a GPU pod serving a **fullscreen, hardware-accelerated KDE Plasma desktop over VNC**. Closes opencharly/pod-kde-vnc#1. Tracking: opencharly/opencharly#1171.

```
sway (headless, pod-sway)  ── wayland-0 ──►  wayvnc (pod-wayvnc) ── :5900
  └─ KWin (nested, --socket wayland-kde), fullscreen in sway
        └─ plasmashell + KDE applications
```

| file | what |

**The design rests on a measured spike** (opencharly/opencharly#1171, comment 7009645068):
- nested KWin under sway, with `app_id: null`, so the kiosk rule matches the title;
- hardware GL on NVIDIA (`OpenGL ES 3.2 NVIDIA 615.78.08`) and on AMD (`radeonsi`);
- `wtype` is garbled by the nested KWin, so input goes through `vnc:`;
- the cap strip has to be on the real binary (a cap-less copy cannot load KWin's built-in Qt platform plugin).
